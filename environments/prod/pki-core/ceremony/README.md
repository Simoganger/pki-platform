# Key ceremony artifacts (public data only)

This folder holds the **public** outputs of key ceremonies performed on the
offline root CA. Nothing here is secret: certificates are public by design.
Committing them gives an auditable, peer-reviewed history of every CA
certificate the root ever signed.

| File | Content | Added by |
| --- | --- | --- |
| `root-ca.pem` | Offline root CA certificate (PEM) | Root ceremony |
| `signed/<ca-key>.pem` | Issuing CA certificate signed by the root, one per key of `var.issuing_cas` | Signing ceremony |
| `minutes/<date>-<purpose>.md` | Ceremony minutes summary (who, what, seals, hash of the video). The signed paper original stays in the vault. | Ceremony master |

**Never** put here: private keys, HSM backup files, PED/smart-card PINs, M-of-N
share material, or HSM partition passwords.

Procedure: [docs/runbooks/external-root-signing.md](../../../../docs/runbooks/external-root-signing.md)

Before committing a signed certificate, verify it:

```bash
openssl x509 -in signed/servers-issuing-g1.pem -noout -subject -issuer -dates -ext basicConstraints,keyUsage,nameConstraints
openssl verify -CAfile root-ca.pem signed/servers-issuing-g1.pem
# The public key must match the CSR generated by AWS Private CA:
diff <(openssl x509 -in signed/servers-issuing-g1.pem -noout -pubkey) \
     <(openssl req  -in servers-issuing-g1.csr        -noout -pubkey)
```
